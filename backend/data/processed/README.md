# Processed Satellite Data Directory

This directory stores intermediate raster products generated during the preprocessing pipeline:
- Boundary-clipped GeoTIFFs (strictly cropped to Madurai district boundary).
- Reprojected GeoTIFFs (aligned to `EPSG:32644` UTM Zone 44N).
- Harmonized spatial resolution (10m resampled grid).
- Cloud-masked valid surface reflectance layers.
