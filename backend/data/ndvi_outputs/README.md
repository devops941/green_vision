# NDVI Outputs Directory

This directory stores calculated scientific products:
- Single-band floating-point 32-bit NDVI GeoTIFF rasters (`[-1.0, +1.0]`).
- Classified categorical integer GeoTIFF rasters (Classes 0 to 4).
- High-resolution colorized PNG visualizations for web display and Leaflet map tiling.
- Histogram frequency plot PNGs for statistical distribution across Madurai.
